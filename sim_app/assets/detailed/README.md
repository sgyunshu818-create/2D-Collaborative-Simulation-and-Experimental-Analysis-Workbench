# 程序化虚拟地形素材

本目录保留 `detailed_virtual` 地形的运行资源，供采用该地形标识的场景和历史记录使用。

地图使用 6144 × 4096 基础纹理、五层共 129 张 PNG 瓦片。`terrain.json` 保存地形尺寸与道路、河流、农田、建筑、机场等显示要素。运行组件为 `sim_app/detailed_terrain.py`，编辑器、运行和回放共用同一视口绘制。

图片和显示要素不自动参与寻路或碰撞。运行仅依赖核心环境；重建资源可使用 `tools/build_detailed_terrain.py`，需要 NumPy 和 Pillow。

默认场景采用广域山区地图，本目录用于兼容其他地形输入。请保留完整目录，避免旧场景或回放缺少底图。
