# 装备与局部地形素材

本目录包含运行时读取的装备图样与小场景底图，均作为界面显示素材使用。

| 文件 | 用途 |
| --- | --- |
| `tank.png` | 履带坦克图样 |
| `armored_car.png` | 八轮装甲车图样 |
| `airplane.png` | 固定翼飞机图样 |
| `drone.png` | 四旋翼无人机图样 |
| `terrain.png` | 小范围虚拟山谷底图 |

装备 PNG 带透明通道。运行时按显示尺寸缩放，叠加红蓝阵营轮廓和标签；地形适度压暗以保持路线和文字可读。

所有素材从本地项目目录加载。图片不提供真实装备性能、地理坐标或通行规则；实际通行限制由场景中的障碍和单位属性决定。
