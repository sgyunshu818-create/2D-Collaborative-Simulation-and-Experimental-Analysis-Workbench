# 广域山区地图素材

本目录提供 `astra_atlas` 地形的源图与运行瓦片。默认场景为项目根目录下的 `configs/detailed_scene.json`。

地图由 5 × 5 个分区组成，虚拟世界范围为 240000 × 160000 仿真单位。原生拼合图为 7168 × 4776 像素，包含山地、峡谷、森林、湖区、平原、村落、农田和机场。中央分区保留小范围山区原图。

| 路径 | 内容 |
| --- | --- |
| `sources/r0_c0.png` 至 `sources/r4_c4.png` | 25 张原始分区图，每张 1536 × 1024 像素 |
| `alignment.json` | 分区衔接和排列参数，供重建使用 |
| `runtime/terrain.json` | 世界范围、分区、瓦片层级与文件校验值 |
| `runtime/0` 至 `runtime/4` | 五层共 192 张 PNG 瓦片 |

运行时只读取可见区域。缓存上限为 48 张瓦片、1 幅背景视口与 64 个地名位图。初始相机显示中央装备区；编辑器支持 25 分区跳转和全域总览。最高 256 倍是交互范围，超过原生影像尺度不会得到新的地形细节。

在项目根目录重新打包运行瓦片：

```powershell
.\.venv\Scripts\python.exe tools/build_terrain_atlas.py --alignment sim_app/assets/terrain_atlas/alignment.json
```

重建使用核心运行环境中的 Pygame，无需安装图像实验的可选依赖。源图用于重新打包和素材一致性检查，运行直接读取 `runtime` 中的瓦片。

地形没有实际经纬度或测绘比例；水系和山脊衔接是视觉近似。图片中的道路、河流和山体不直接参与寻路或碰撞计算。
